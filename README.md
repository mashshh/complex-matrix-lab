# Лабораторная работа 1: матрицы комплексных чисел

Класс для работы с матрицами комплексных чисел.
Операции: сложение, умножение, деление, транспонирование, определитель.

программа складывает матрицы, если размеры совпадают, умножают, если число столбцов первой равно числу строк второй, делят, если матрица-делитель квадратная и невырожденная, транспонирует, вычисляет определитель методом Гаусса

если операция невозможна, программа выводит сообщение об ошибке и продолжает работу. Некорректный ввод (например, буквы вместо числа) тоже обрабатывается: данные запрашиваются заново.

Классы:
- Complex - комплексное число
- ComplexMatrix - матрица и операции над ней
- ConsoleReader - чтение данных с консоли
- Main - консольное меню

для матриц написан один класс, A, B, R - объекты

работа программы:
1 - Ввести матрицу A
2 - Ввести матрицу B
3 - Показать матрицы A, B и последний результат R
4 - Сложить
5 - Умножить
6 - Разделить (первая * вторая^-1)
7 - Транспонировать
8 - Определитель
0 - Выход

ввод комплексного числа:
задаётся двумя числами через пробел: сначала вводится действительная часть, потом мнимая. например число 3 - 2i вводится как 3 -2

результат каждой операции (кроме поиска определителя) сохраняется как матрица R и хранится, пока работает программа, поэтому можно выполнять цепочки операций
